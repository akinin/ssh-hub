# SSH Hub: инструкции для агентов

## Проект

Нативное приложение для macOS 14+ на Apple Silicon: записи SSH, Serial, веб-ссылки, документация, вложения, SFTP, ключи, туннели и Nmap. Интерфейс и пользовательская документация — на русском языке. Используйте термин «запись» для объекта приложения; «SSH-алиас» — только для блока `Host` в SSH-конфиге.

## Структура

- Несколько карт в профиле: `TopologyDocument.id/name`, отсутствующий id читается как profileID, имя — «Основная карта». Старый файл/Keychain namespace сохраняются; новые mapID имеют отдельные файлы и credential scope. До 50 карт/профиль. `EntryPage.topologyMapID`/`topologyKey` используют nil для старой карты и `map:<UUID>` для остальных; restore исключает повторные/удалённые карты и ничего не запускает. Удаление закрывает все вкладки карты и удаляет модели, чтобы старое состояние не воскресило файл. Копия не копирует секреты. Архив проверяет уникальные mapID, remap профиля/карты и rollback всех новых файлов.
- В 2.16 `TopologyCanvas.swift`/`TopologyPanels.swift` — pinch с неподвижным anchor, Cmd-выделение, групповые перемещения/выравнивание, связи перетаскиванием, области/сворачивание и создание записей через обычный редактор. Сохранение привязывает стабильный ID к существующему узлу; отмена не создаёт запись. `TopologyExport.swift` выдаёт PNG/SVG только из явно переданных узлов/связей/меток, без заметок/настроек/credentials; ограничивайте пиксели и экранируйте XML.
- Статус контроллера, TCP с Mac и факты портов имеют независимые время/источник. Периодика обновляет настроенные API и TCP только после явного включения. Резервный WAN в ожидании не является offline. Журнал ограничен 500 реальными изменениями; не синтезируйте прошлое. Объединяйте только однозначные авто-связи, сохраняя provenance, ручные связи и параллельные порты.
- UniFi `/networks` + details дают VLAN/IPv4-подсети; `/wifi/broadcasts` — только безопасный overview, никогда не запрашивайте Wi-Fi detail с паролями. Членство по IP отмечается inferred и не определяет физическую топологию. Клиентские SSID/диапазон/vendor и WAN ISP/роль отсутствуют в официальном Integration API — не выдумывайте их. RDAP запрашивается отдельной кнопкой только для публичного WAN, результат — владелец диапазона, не гарантированный бренд ISP; ручное название не заменяется.

- В 2.15 `TopologyData.swift`/`TopologyModel.swift`/`TopologyView.swift`/`TopologyEditors.swift`/`TopologyRouterView.swift`: отдельная карта профиля и SSH-конфига, ручные поля/WAN/связи отделены от автофактов; импорт сохраняет UUID/расположение. Не выводите физическую топологию из ARP/подсети. Источник и время портов, сервисов и WAN независимы. Доступность — явная TCP-проверка с Mac; неизвестные/устаревшие значения не должны выглядеть актуальными. Workers принадлежат модели; pending живёт до фактического drain после Stop. Не допускайте очистку старой задачей нового worker/askpass.
- `TopologySSH.swift` читает фиксированные однострочные команды Linux/macOS/RouterOS без sudo. `TopologyUniFi.swift` и `TopologyRouterAPI.swift` — только ограниченные read-only HTTPS API. TLS/SSH trust не отключать; редиректы отклонять без передачи credentials. API-ключи/пароли только в отдельных Keychain namespaces с привязкой к контроллеру, пользователю, профилю и конфигу; не в Codable/логах/архивах. Не запрашивайте полные конфиги, приватные ключи WireGuard или изменяющие endpoints. RouterOS Ethernet monitor — только once.
- Карты входят в зашифрованный архив. Проверяйте старые архивы, maps-only, конфликт профиля/карты, remap записей и rollback с atomic exclusive publish. Сохранённая карта с ошибкой чтения блокирует редактирование. Тесты `Topology*Tests.swift` и `Topology*IntegrationTests.py` используют синтетические данные и собственные localhost HTTP/SSH/TLS, не пользовательские роутеры/контроллеры. Интерфейс проверяйте с несколькими WAN, обычным/узким окном, переносом и закрытием вкладки, восстановлением без автозапуска.

- В 2.14 `RemoteLogs.swift`/`RemoteLogsView.swift` — явно запускаемые bounded captures journal/file/Docker/RouterOS/macOS, model store-owned. Пауза только UI; stop на close/profile/quit, не onDisappear. Сохранённые фрагменты — обычные вложения. `RemoteLogsTests.swift` собирается с -DREMOTE_LOGS_TEST, `RemoteLogsIntegrationTests.py` использует только свой localhost sshd/ProxyJump.
- `RecordInventory.swift`/`RecordInventoryView.swift`: manual/draft и до 20 авто-снимков. Сбор не заменяет ручные поля; подтверждение применяет неизменяемый InventoryApplyProposal с выбранным snapshot/fields. Ошибка load блокирует запись и сбор до успешного reload. Inventory/WinBox — optional поля полного зашифрованного архива, не JSON-экспорта. Проверяйте merge/cancel, старый архив, конфликт ID, gateway remap и rollback новых файлов.
- `WinboxSettings.swift`/`Winbox.swift`/`WinboxView.swift`: только установленный нативный com.mikrotik.winbox, адрес/login без password в argv, отдельный PID от NSWorkspace. Запрос выхода только собственному процессу, чужие WinBox не трогать; при закрытии окна процесс может жить. Туннель store-owned, no direct fallback, restore не запускает. `WinboxTests --lifecycle` запускает только свой временный mock Mach-O app, не /Applications/WinBox. `TunnelSession.pending` отслеживает реальный drain приватных SSH workers независимо от main actor; учитывайте в завершении и восстановлении.
- `SSHLoginPolicy.swift` разрешает auto-password новых flows только после bounded `ssh -G` с теми же wrapper defaults/System Include: ProxyJump/ProxyCommand/ошибка/отмена → ручной askpass без автоматической отправки пароля назначения. Не отключайте trust checks. Политика не читает Keychain; тестируется на отдельных конфигурациях в InventoryIntegrationTests.

- В 2.13 `DocumentationVisualPage.swift` содержит локальный contenteditable-движок, `DocumentationVisual.swift` — WKWebView-мост. Документы/черновики/история остаются Markdown; смена режима не должна перезаписывать текст. Ввод и форматирование сериализуются с экранированием; вставка только plain text, drop запрещён, CSP и navigation delegate запрещают внешние ресурсы. `DocumentationVisualTests.swift` проверяет выделение/undo/поиск/замену и безопасную вставку в скрытом тестовом окне с AppKit undo manager. Не отключайте CSP и не передавайте пользовательские строки интерполяцией в JavaScript — используйте arguments.

- В 2.12 `ExtraTools.swift`/`ExtraToolsView.swift` добавляют iperf3, Whois/RDAP, Bonjour, SSH и локальные преобразования. iperf3 устанавливается только по явной кнопке, не включается в bundle; тестовый экземпляр можно собирать во временной папке из официального архива с SHA-256. Синтетический TCP/UDP-трафик тестируйте только на localhost.
- RDAP использует HTTPS bootstrap IANA и самый длинный подходящий префикс IP; plain HTTP разрешён только внутренним флагом для localhost-теста. WHOIS не шифруется. Не отключайте TLS/SSH trust checks; ключи ssh-keyscan не записывайте в known_hosts.
- `BonjourScanner` использует DNS-SD на своей serial queue: создание/deallocate refs и callbacks на той же очереди, ограниченные время/число сервисов, отмена при закрытии вкладки. Интеграция регистрирует и ищет собственный сервис через LocalOnly, не просматривает чужую сеть. В Info.plist поддерживайте NSBonjourServices и описание локальной сети.
- `FileChecksum` читает обычный файл до 2 ГБ через O_NOFOLLOW и fstat, проверяет размер/mtime после чтения и отмену между блоками. Ввод преобразований до 1 МБ, не хранится в preferences/архиве. Проверки `ExtraToolsTests.swift`/`ExtraToolsIntegrationTests.py` используют только свои стенды и фиктивные материалы.

- `NetworkTools.swift`, `ToolkitToolsView.swift`, `ToolkitRuntime.swift`, `IPCalculator.swift`: единая вкладка Nmap/DNS/TCP/TLS/IP/Ping/HTTP/Wake-on-LAN. Сеансы принадлежат хранилищу, переключение раздела сохраняет результат; закрытие вкладки/профиля останавливает операции. TLS-периодика работает только при видимом инструменте. HTTP использует curl без curlrc, проверяет сертификаты, не принимает URL с учётными данными. Wake-on-LAN отправляет один UDP magic packet, тестируется только на loopback.
- В 2.11 удалены общие библиотеки материалов и сравнение файлов. `RetiredLibraryData.remove` удаляет только точный файл `KnowledgeLibrary.json` (или саму ссылку), без резервной копии, не обходит каталоги. Архивы 2.10 читаются с игнорированием удалённых полей. Библиотека команд, документация/вложения записей и шаблоны записей сохраняются.
- `Nmap.swift`, `NmapView.swift`: ограниченные типизированные аргументы, TCP connect без привилегий, пять выбранных NSE, 24 встроенных и до 200 своих шаблонов. Шаблон не хранит цель и не запускается при выборе. Свои шаблоны приватны и входят в зашифрованный архив; конфликт ID remap и откат проверяются. XML ограничен 8 МБ, сущности не разрешаются. Проверяйте discovery, все порты, исключения, NSE, статусы/причины/узлы, отмену/таймаут и localhost scan. Никогда не сканируйте пользовательские адреса при тестах.

- `App.swift`: AliasStore, главное окно, панель записи, редактор существующих SSH-алиасов.
- `LocalConnections.swift`, `RecordEditorView.swift`, `RecordChooserView.swift`: локальные записи и выбор типа.
- `ConnectionLaunch.swift`, `CommandTask.swift`: аргументы CLI для новых консольных транспортов и ограниченный отменяемый запуск без shell. `TelnetHelper.c`: встроенный Telnet с IAC/NAWS и восстановлением termios.
- `ConnectionPages.swift`, `RemoteFiles.swift`, `RemoteFilesView.swift`: встроенный веб и FTP/FTPS/WebDAV. `VNCConnection.swift`, `DesktopSession.swift`, `RDPHelper.c`: графические вкладки. `build-rdp.sh` собирает статические FreeRDP/OpenSSL из архивов с фиксированными SHA-256; готовая сборка не зависит от Homebrew.

- `WorkspaceSnapshot.swift`, `WorkspacePersistence.swift`: сохранение рабочей области, перенос вкладок и отдельные окна. Восстановление не запускает транспорт автоматически.
- `BackupArchive.swift`, `BackupRestoration.swift`, `BackupView.swift`: зашифрованный полный архив и восстановление с откатом новых файлов при ошибке.
- `RecordTemplate.swift`, `RecordTemplates.swift`, `ActionPalette.swift`, `Availability.swift`, `TCPAvailability.swift`, `SessionJournal.swift`: шаблоны, палитра, выбранные TCP-проверки и журнал сеансов.

## Сборка и проверки

Из корня репозитория:

```sh
zsh build.sh /private/tmp/ssh-hub-build
python3 SerialIntegrationTests.py '/private/tmp/ssh-hub-build/SSH Hub.app/Contents/MacOS/SSHSerial'
zsh package-dmg.sh /private/tmp/ssh-hub-build /private/tmp/ssh-hub-dist --skip-build
```

Нужны macOS, Command Line Tools с совместимым SDK и Python 3 для интеграционных проверок. `build.sh` собирает приложение и транспортные помощники, запускает проверки конфигурации, SFTP, туннелей, документации, записей, Nmap и консоли. Скрипт предпочитает установленный стабильный SDK macOS 26.5, если он доступен; иначе использует SDK из `xcrun`.

Проверяйте изменённое поведение. Для интерфейса проверяйте обычное и узкое окно, сворачивание боковой панели, переключение и закрытие вкладок. Плитки действий должны иметь одинаковую высоту; длинный заголовок не должен растягивать одну плитку. Таблицы и редакторы ограничивайте размером рабочей области, чтобы они не сдвигали содержимое под toolbar.

Сетевые интеграционные проверки выполняйте на локальных тестовых серверах. Nmap не должен автоматически сканировать адреса пользователя. Serial можно проверять виртуальным PTY; не объявляйте физический адаптер проверенным без такой проверки. Завершайте только процессы, созданные своей проверкой.

## Данные и совместимость

- Сохраняйте `CFBundleIdentifier` `com.olshaniki.ssh-aliases`, идентификаторы Связки ключей и стабильные ID записей: от них зависят существующие данные.
- Новые поля Codable должны читать старые файлы; проверяйте импорт/экспорт и переименование. Пароли, приватные ключи, документация и вложения не должны попадать в JSON-экспорт записей.
- Изменения SSH-конфига должны сохранять остальные директивы и комментарии, иметь резервную копию и поддержку отмены. Проверки не должны менять настоящий `~/.ssh/config`.
- Пароли храните в Связке ключей, не в исходниках, аргументах процессов, логах или UserDefaults. Не отключайте проверку ключа SSH-сервера.
- Запускайте инструменты через Process с массивом аргументов. Не подставляйте пользовательские значения в shell-команды. Исключения — явные команды для копирования или запуска в выбранном пользователем Терминале, с корректным quoting.
- Nmap и Homebrew не входят в сборку. Установка выполняется явно пользователем из интерфейса через официальный установщик в Терминале; пароль macOS приложение не принимает.
- Serial-порт принадлежит одному сеансу. При остановке освобождайте порт и восстанавливайте termios; дублирование активного Serial-сеанса не допускается.

## Публикация

Начиная с 2.10 копия старого приложения хранится только во время установки для отката. `cleanupBackups` удаляет только UUID-каталоги `.SSH-Hub-backup-*.app` рядом с текущим SSH Hub, с тем же bundle ID и версией не новее текущей; ссылки и посторонние приложения пропускаются. Не удаляйте пользовательские данные или произвольные папки.

В репозиторий не добавляйте пользовательские SSH-конфиги, ключи, пароли, логи сеансов, данные Application Support, локальные пути и сборочные архивы. Используйте вымышленные адреса и примеры. Перед публикацией проверяйте список файлов и содержимое на секреты. Сборки и DMG размещайте в GitHub Releases, исходники — в Git. Не изменяйте стороннюю лицензию.

Для встроенного обновления релиз должен быть стабильным Latest с тегом `vX.Y.Z` и файлом `SSH-Hub-macOS.zip`, содержащим `SSH Hub.app`. SHA-256 берётся из метаданных asset GitHub; отсутствие digest должно блокировать установку. Не добавляйте токены в клиент, не разрешайте другие источники или произвольные shell-команды. Проверки `UpdateTests.swift` запускаются сборкой; `UpdateIntegrationTests.py` проверяет helper на временных копиях без запуска UI.

При выпуске обновляйте обе версии в `Info.plist`, README и собирайте согласованные приложение, DMG и архив исходников. Установку в `/Applications` выполняйте, когда пользователь её запросил, с возможностью восстановления предыдущей сборки. Не утверждайте, что приложение подписано Developer ID или нотарифицировано: текущая сборка использует локальную ad-hoc подпись.

## Рабочая область

Одна вкладка принадлежит одной панели. При переносе сохраняйте тот же сеанс и не размещайте один native TerminalView одновременно в двух контейнерах. Закрытие одной вкладки не должно отключать соседнюю. Раздел документации передавайте явно в представление панели, не берите его из глобально выбранной вкладки. SFTPModel принадлежит хранилищу вкладок; не отключайте его в onDisappear при переключении. Закрытие вкладки завершает сеанс и очередь. При отмене/ошибке очередь останавливается. Не перезаписывайте существующие файлы; ссылки и специальные файлы не передавайте. Проверяйте рекурсивные папки, пустые папки, коллизии, отмену и очистку staging.

Команды консоли: `SavedCommands.swift` (локальное хранилище), `ConsoleCommandsView.swift` (полоса и настройки). Настройка Enter относится ко всей записи и по умолчанию выключена. Не допускайте переводов строки и управляющих символов в тексте команды: они обходят этот выбор. Отправляйте байты только в выбранный сеанс записи на main actor. Команды не включайте в JSON-экспорт; сохраняйте при переименовании и копируйте при дублировании. Проверки входят в WorkspaceTests.

В версии 2.6 полный зашифрованный архив отдельно включает команды, документацию и вложения; обычный JSON-экспорт сохраняет прежние ограничения. Новые поля команд должны читать данные 2.5. Переменные команд экранируйте для оболочки. Запись вывода сеанса включается только пользователем; TCP-проверки выполняются только для выбранных серверов. `AdvancedTests.swift` проверяет восстановление рабочей области, совместимость команд, шифрование/повреждение архива, конфликты и откат восстановления, журнал и TCP на localhost.

В 2.7 описания команд и поле библиотеки в архиве необязательны для чтения старых данных. Предустановки не отправляйте на серверы и не назначайте записям автоматически. `UpdateTerminationTests.swift` запускает собственное тестовое приложение: проверяет выход с sheet, асинхронную очистку и ограничение времени. После `.terminateLater` main-queue Task может не исполняться: используйте таймер, добавленный в common и modalPanel режимы RunLoop.

В 2.8 панель записи одна во всей рабочей области: повторно используйте ID, место вкладки и отдельное окно; при миграции удаляйте только лишние `.overview`. `transport` в записях/JSON необязателен. Пароли новых протоколов передаются RDP и curl через stdin, а не argv/env/файлы. Не включайте `--insecure` или IgnoreCertificate. Исключение доверия RDP/веб требует явного подтверждения отпечатка для адреса; изменённый сертификат подтверждается снова. Транспорт и очереди принадлежат хранилищу вкладок, закрываются только явно, не в onDisappear. `RemoteProtocolTests.swift` и `RemoteIntegrationTests.py` проверяют новые клиенты на временных локальных стендах; `RDPFixture.c` не входит в приложение. Не объявляйте реальные Windows/Android/контейнеры проверенными без такого теста. Лицензии FreeRDP/OpenSSL включайте в ресурсы; deployment target зависимостей — macOS 14.

В 2.9 `WorkspaceProfiles.swift`, `ProfilesView.swift` хранят профили с общей библиотекой и отдельными снимками рабочей области. Удаление профиля сохраняет записи; переключение завершает старые транспорты без автоматического входа в новые. `TabCustomization.swift` защищает закреплённые вкладки от всех пользовательских массовых закрытий; внутреннее удаление несуществующей записи и смена профиля используют force. Новые Codable-поля необязательны. `ConnectionTunnel.swift` владеет своим TunnelSession и каналом askpass, не общим TunnelManager. Для RDP/веба сохраняйте имя TLS-сервера через SOCKS и запрещайте fallback в прямую сеть. `RDPChannels.c` загружает cliprdr/rdpdr/drdynvc/disp через LoadChannels (ядро пересоздаёт channels при подключении), не перенаправляйте автоматически все диски. Общий буфер только текст, по выбору пользователя и при активном RDP. `RDPAdvancedIntegrationTests.py` проверяет Unicode, чтение/запись выбранной папки, мониторы и изменение кадра на localhost; `RDPFixtureChannels.c` остаётся только в стенде.
