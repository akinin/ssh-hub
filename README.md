# SSH Hub

Нативное приложение для macOS, которое объединяет подключения к серверам, терминалы, файлы и сведения об инфраструктуре в одной рабочей области. Подходит для повседневного администрирования Linux, сетевого оборудования и других удалённых устройств.

**macOS 14 и новее · Intel и Apple Silicon · интерфейс на русском языке**

[Скачать последнюю версию](https://github.com/akinin/ssh-hub/releases/latest) · [Все доступные релизы](https://github.com/akinin/ssh-hub/releases)

## Возможности

| Раздел | Что можно делать |
| --- | --- |
| Подключения | SSH во встроенной консоли или внешнем терминале, локальная оболочка, Serial, Telnet, RDP и VNC. |
| Файлы и веб | Передавать файлы по SFTP, FTP/FTPS и WebDAV, открывать веб-интерфейсы во вкладках или браузере. |
| Рабочая область | Использовать вкладки, две панели, отдельные окна и профили; находить записи через поиск, избранное и меню macOS. |
| SSH-ключи и доступ | Создавать ключи, устанавливать и проверять публичный ключ на сервере, выбирать пользователя и способ входа, хранить приватные ключи и пароли в зашифрованной базе. |
| Маршрутизация | Подключаться через SSH-шлюз, управлять пробросами портов, SOCKS5 и профилями WireGuard. |
| Инвентаризация | Собирать сведения об ОС, процессоре, памяти, плате, BIOS, сетевых интерфейсах, портах и накопителях; просматривать SMART, если устройство и права доступа позволяют. |
| Диагностика | Проверять доступность, DNS, TLS и порты, работать с Nmap, удалёнными логами и проверками безопасности. |
| Материалы записи | Хранить документацию, вложения, заметки, лицензии, сведения об оплатах и покупке оборудования. |
| Инфраструктура | Создавать сетевые карты, подключать интеграции, просматривать мониторинг и уведомления. |
| Учётные данные | Работать с KeePass и кодами MFA, использовать общие учётные данные для записей. |
| Автоматизация | Запускать сохранённые команды и пользоваться ИИ-помощником с просмотром и подтверждением предложенных действий. |

Порядок действий, плитки карточки, контекстное меню, значки списка и плотность интерфейса настраиваются. Для отдельных записей можно задать собственное оформление.

## Установка

1. Скачай **SSH-Hub-macOS.dmg** из [последнего релиза](https://github.com/akinin/ssh-hub/releases/latest).
2. Открой образ и перетащи **SSH Hub.app** в **Applications / Программы**.
3. Запусти приложение. Одна универсальная сборка работает и на Intel, и на Apple Silicon.

Для обычной работы готового приложения не нужны инструменты разработки. Отдельные функции используют внешние утилиты: например, Nmap устанавливается отдельно, а аппаратная инвентаризация зависит от утилит и прав на удалённом устройстве.

Новые сборки подписываются сертификатом **Apple Developer ID** и перед распространением проходят нотарификацию Apple. Устанавливать собственный сертификат или вручную менять доверие не требуется. В настройках отображается статус подписи. [Подпись и нотарификация](Signing/README.md).

## Начало работы

- **База данных.** При запуске выбери файл базы или создай новую. Открой её мастер-паролем; на этом Mac можно включить Touch ID. Без открытой базы записи недоступны.
- **Существующие подключения.** Действие «Перенести прежние данные» импортирует SSH-конфиг, настройки и сохранённые секреты в новую базу с проверенной резервной копией.
- **Новая запись.** Выбери тип подключения, укажи адрес и параметры доступа. Запись, выбранный SSH-ключ и SSH-алиас сохраняются внутри открытой базы.
- **Подключение.** Открой запись и нажми «Подключиться». SFTP, документация, инвентаризация и другие действия доступны в её карточке.
- **Организация.** Собери записи в папки, добавь избранное и настрой профиль рабочей области. Быстрый поиск доступен из строки меню macOS.
- **Инвентаризация.** Запусти сбор явно, просмотри полученные значения и сохрани нужные изменения в карточку устройства.

## Данные и резервные копии

База обязательна для работы приложения и может использоваться полностью локально. В ней хранятся записи, пароли, MFA, SSH-ключи, документация, вложения, инвентаризация, профили, VPN и настройки интеграций. При блокировке база закрывается, записи исчезают из интерфейса, встроенные сеансы завершаются. KeePass остаётся внешней интеграцией: подключается отдельный KDBX-файл.

Необязательная [облачная синхронизация](SyncServer/README.md) подключается входом в учётную запись собственного сервера. Пользователей создаёт администратор; самостоятельной регистрации нет. Обмен запускается по кнопке, данные шифруются на Mac до отправки, конфликты разрешаются явно. Пароль входа в облако и мастер-пароль шифрования — разные пароли. Зашифрованный обмен включает встроенные SSH-ключи, секреты VPN и настройки интеграций. Внешние KeePass-файлы не передаются; привязку на другом устройстве нужно настроить отдельно.

Мастер-пароль не сохраняется и не восстанавливается через сервер. SQLite служит контейнером; имена и содержимое объектов шифруются AES-256-GCM. Для Touch ID в Связке ключей этого Mac хранится только защищённый ключ разблокировки базы. На другом Mac база открывается мастер-паролем, затем Touch ID включается заново. Резервная копия базы включает пароли, MFA и SSH-ключи.

Для переноса основных параметров записей используется JSON-экспорт. Для резервного копирования материалов и рабочей области предусмотрен полный зашифрованный архив. Обычный JSON-экспорт не включает пароли, приватные ключи, документацию и вложения.

Перенос и обновление базы сохраняют зашифрованную копию и оставляют старые файлы и Связку ключей без удаления. После переноса приложение читает данные только из базы. Старые внешние `ssh alias` продолжают работать со своим конфигом, но изменения записей базы его автоматически не переписывают. Восстановление рабочей области открывает вкладки без автоматического подключения к серверам.

## Обновления

Проверка обновлений доступна в приложении. Пакет проверяется по контрольной сумме и подписи перед заменой установленной версии. Готовые сборки и исходники доступны на странице релизов GitHub.

История изменений доступных версий находится в [описаниях релизов](https://github.com/akinin/ssh-hub/releases); более ранние изменения — в истории Git.

## Разработка

[Сборка и проверки](docs/BUILDING.md) · [Подпись приложения](Signing/README.md) · [Инструкции для работы с кодом](AGENTS.md)

Код приложения находится в `Sources/SSHHub/`, поддержка консоли — в `Sources/ConsoleSupport/`, нативные помощники — в `Helpers/`, скрипты сборки — в `Scripts/`. Метаданные приложения лежат в `Resources/`, генератор иконки — в `Tools/`, проверки — в `Tests/`. Зависимости находятся в `Vendor/` и `WireGuardHelper/vendor/`; их лицензии сохранены рядом с исходниками. Скрипты сборки формируют комплект лицензий для встроенных помощников.
